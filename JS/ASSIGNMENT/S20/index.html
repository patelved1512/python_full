Tasks 10 & 11: 5 Common Bugs Checklist & Fixes

Bug Description Fix
Double Adds Multiple rapid clicks add duplicate items to the cart or list. Check item existence (`find`/`some`), disable button post-click, or update quantity only.
Empty / Blank Fields Submitting forms with empty inputs creates corrupt data entries. Trim inputs and validate values before updating array state.
Null / Undefined Values Passing null/undefined values to functions crashes UI rendering. Add guard clauses and default parameter fallbacks before pushing to state/arrays.
Out-of-Range Inputs Entering invalid values (e.g. rating > 5 or negative quantity). Enforce min/max boundaries in JS validation alongside HTML attributes.
Missing UI Feedback User is unaware whether action succeeded or failed. Conditionally display clear error or success alert messages below elements.
